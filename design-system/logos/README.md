# Logos

The Quode duck in three crops. All are SVG with a black outline, white body and #FF751F orange beak; use them as images (`<img>`), never recoloured.

- **Duck.svg**: the full mascot with three question marks. Minimum height 96px.
- **duck-mark.svg**: head only, square. Minimum 32px; below that use the app icon.
- **app-icon.svg**: the head on a beak-yellow (`accent`) rounded tile, 512×512. Use for the PWA icon, favicon and social previews.

The wordmark is plain text "Quode" in Bricolage Grotesque 700 next to the mark; there is no separate wordmark file.
