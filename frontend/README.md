# frontend

React + TypeScript (strict) + Vite, Tailwind CSS v4, React Router, TanStack Query, React Hook Form + Zod.

- `npm run dev`, `npm test`, `npm run lint`, `npm run build`, `npm run generate:api`: see [docs/onboarding.md](../docs/onboarding.md).
- Theme: generated from [`../design-system/tokens.json`](../design-system/tokens.json) by `scripts/generate-theme.mjs`; follow the rules in [`../design-system/README.md`](../design-system/README.md).
- UI text: `src/messages.ts`. API types: `src/api/schema.d.ts` (generated).
