# ADR-0010: Minimal auth and PWA in the MVP

- **Status:** Accepted
- **Date:** 2026-10-06

## Context

Using the app on a phone means it's on the internet.

## Decision

Single-user login in the MVP (mechanism: ADR-0015). Ship as an installable PWA.

## Consequences

Data is protected from day one; home-screen access without native apps.
