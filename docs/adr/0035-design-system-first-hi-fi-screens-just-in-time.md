# ADR-0035: Design system first, hi-fi screens just in time

- **Status:** Accepted
- **Date:** 2026-10-06

## Context

Designing every screen up front wastes work once real use reveals problems; no design at all makes every frontend task guess.

## Decision

A small design system now (tokens, type, components, dark mode) validated on two hi-fi screens. Hi-fi screens for each milestone are made during its task breakdown. After M2, a friction log drives design fixes. Mascot illustrations in M4.

## Consequences

Tokens become the Tailwind theme from day one; screens are designed with real usage in mind.
