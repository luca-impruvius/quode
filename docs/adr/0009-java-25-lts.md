# ADR-0009: Java 25 (LTS)

- **Status:** Accepted
- **Date:** 2026-10-06

## Context

Choice between Java 21 and 25, both long-term support releases.

## Decision

Java 25 with a Spring Boot version that supports it.

## Consequences

Newest language features and a stronger interview talking point. Small risk of library lag, checked when the skeleton is built.
